予定は生活日付順・開始時刻順です。ICSファイルを作成して、対応するカレンダーに追加できます。

時計の設定

境界時刻ちょうどから新しい生活日付になります。設定を変えても予定の実日時は変わりません。アナログ時計は通常の12時間表示です。

アプリとして使う・インストール

インストールせず、このページのままでも使えます。

iPhone / iPad：Safariでこのページを開き、共有メニューから「ホーム画面に追加」を選びます。MacのSafari：対応環境では「ファイル」から「Dockに追加」。Chrome / Edge：アドレスバーのインストールアイコン、またはブラウザのメニューをご確認ください。表示はOS・ブラウザにより異なります。

保存・バックアップとプライバシー

予定と設定はこの端末・ブラウザ内に保存され、別の端末には自動同期されません。入力内容をサーバーへ送信しません。

サイトデータを削除すると予定も失われます。プライベートブラウズでは保存が維持されない場合があります。大切な予定はICSとして書き出して保管してください。

ICSは自動同期ではありません。保存・共有したファイルを対応カレンダーで開いて追加してください。再取り込み時に重複するかどうかはカレンダー側によります。PWAの編集・削除は、追加先カレンダーへ反映されません。

一度オンラインで準備が完了すると、時計・設定・予定の編集・ICS作成をオフラインで使えます。ブラウザによりキャッシュや保存データが削除されることがあります。

オフラインの準備を確認中…

通知、アラーム、常に最前面、クラウド同期、外部カレンダーへの直接登録はありません。
